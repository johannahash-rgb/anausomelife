A note to the editor

Hello, reader.

A question, a correction or a useful detail we missed? We would like to hear it.

Send us a note.

hello@anausomelife.com

For a correction, please include the page link and the detail that needs a second look. If a venue has changed its access arrangements or a product’s specifications have changed, a link to the current information is particularly helpful.

Please leave private care records, identifying information about children and other sensitive details out of ordinary email. A brief description of the question is enough to begin.
