# Site experience audit — 26 October 2026

The journal review revealed a wider pattern: useful stories and tasks were preceded by too many navigation choices, followed by repeated prose and optional tools competing for attention. This pass simplifies those patterns while retaining the site's five chapters, original photography, content destinations and working tools.

## Scope and method

- Inventory: all 200 canonical pages in the finished public edition. The source has 198; the publication build creates two additional reader pages.
- Static publication check: 233 HTML documents, including utility/redirect/print documents, local links, assets, fragment targets, headings, metadata and sitemap coverage.
- Browser layout check: every canonical page at 320, 390 and 1280 CSS pixels. The accompanying JSON records each page and viewport.
- Focused interaction checks: library search/filter/reset, communication-note creation and focus, guide contents links into a folded checklist, checklist progress/reset, and native disclosures. Regression tests cover anchor/control preservation, repeated generation, deep-link opening, Escape focus and print-state restoration.
- Visual spot checks cover representative article, guide and directory entrances. This is a site-wide structural and responsive UX audit with targeted interaction checks, not a manual usability study of every possible state or a claim of complete accessibility compliance.

## Findings and changes

| Area | Friction | Result |
| --- | --- | --- |
| Shared reading layout | Breadcrumbs repeated the full headline; topic and format rows delayed the introduction | Breadcrumbs show the route back. Related topics move to a closed section later in the page. Contents follow the introduction. |
| Stories and practical guides | Repeated cover artwork/decks and exact paragraphs; optional checklists interrupted reading | Keep the first authored copy and unique guidance. Worksheets become an optional section after the practical content. 64 pages use this worksheet pattern. |
| Story extras | Sharing packages and picture-card tools added substantial material to the reading path | 73 pages place these extras in labeled native disclosures. Existing downloads, captions, permissions and fragment links remain available. |
| Library and places | Full filter panels and illustrated browsing routes competed with search | Keep search visible; reveal secondary fields on request. Move optional browsing routes after the result workspace. Active filter labels remain visible. |
| Calendar | Several ways to choose and view events appeared together | Keep place, date and search up front. Put cost with advanced filters and the calendar/map switch in one optional section. Event data and actions remain intact. |
| Picture-card collection | Category controls and story collections preceded the main task | Start with picture search; offer category filters on request. Keep selection, editing and print-sheet behavior. |
| Planning toolkit | Several full worksheets appeared at once | Choose the planning card to open. Inputs, output and existing section links are preserved. |
| Communication notes | Every field was visible and output actions were active before a note existed | Expand later sections as needed. Output actions become available after generation, and focus moves to the completed note. |
| Little Black Book | Existing filter disclosure needed to stay coherent with the shared pattern | Preserve its existing Filter & sort control and keep Clear within it; avoid a second reset-only disclosure. |
| Family Agreements | An illustration overflowed a 320px screen by 13px | Constrain its width to its container while keeping its proportions. |
| About, policies, contact, media, glossary and other hubs | Some already had a clear reading/task structure | Apply the smaller shared breadcrumb/related-navigation improvements where relevant. Keep policy text, contact routes, visible media examples, glossary search and primary content available. |

137 pages have related-topic disclosures; 111 fold broad secondary exit links. These groups overlap. In total, 171 of the 200 canonical pages use one or more of the new disclosure patterns. The remaining pages retain their focused content structures.

At 390px, the first title moves earlier on 168 pages; the median improvement across the 200 pages is 174px. These measurements describe this browser's rendered layout, not a loading-performance metric.

## Verification and limits

The finished publication passes the static site audit with no reported issues. Existing story-sharing, editorial asset, picture-card, navigation, accessibility-tool, inquiry and reader-publication checks pass. The new tests protect control attributes, original fragment destinations, one visible primary heading, idempotent processing, deep links, Escape and print restoration.

All 600 final viewport checks are recorded in `ux-audit-2026-10-26.json`. The browser scan checks page-width overflow, loaded-image failures and main/heading structure. It does not prove that every lazy-loaded or externally embedded resource works, and it does not replace screen-reader or real-reader testing. External websites and organizer facts were not re-audited in this UX pass.

The Wayne Newton press entry, journal priorities, real photography, private-form behavior, publishing rights and overlapping taxonomy data remain intact. No external messages were sent.

## Maintenance

Run the full publication sequence, because some pages are generated during deployment. Run `tests/test_page_simplicity.py` and `tests/test_reading_ease.cjs` alongside the existing checks. Keep optional controls native and usable without JavaScript. Do not add another always-visible panel when a page already provides an adequate control for the same task.
