# Practical site review — 5 October 2026

Owner requested useful parent-facing tools, no automatic family-photo communication cards, concise illustration captions, and a careful page-by-page review. Publication remains authorized.

## Decisions

- Kept the working local photo/card editor. Removed the free-text suggestion facade; six actual object pictures are visible immediately. A custom food, object or destination can use the visitor’s own photo. No upload service.
- Removed automatic article-hero cards and the misleading collection of generic venue scenery/family-photo cards. The retired script remains a harmless file for cached pages.
- Kept printable handoff forms, outing plans, directory/calendar filters, and the optional original story reader.
- Simplified 64 guide pages to one visible checklist; removed duplicate tabs, sidebar reminders and decorative “visual plan” sequences. Preserved their section IDs. Checklist content and full practical instructions remain.
- Communication notes now produce usable print/copy notes, without duplicate AI prompts or three nominal formats with substantially identical output.
- Reduced duplicate related-content widgets on tools and pages already carrying related links.
- Updated public captions to “Original editorial illustration” while preserving generated-art provenance and the site disclosure.
- Added NOVA (wheelchairs and mobility products), Yoto (our Yoto Mini), Vineyard Vines and Danskin to the shared Tried & True registry and static fallback. The catalog now contains 53 names. No new logo assets or purchase claims were invented.

Identity sources checked: https://www.novajoy.com/ ; https://us.yotoplay.com/yoto-mini ; https://www.vineyardvines.com/ ; https://danskin.com/ . User clarified NOVA and confirmed Yoto, then requested the two clothing brands. The “Omni juice” item remains unidentified.

## Verification and limits

- Parsed every HTML page and inventoried its title, controls, scripts, references and IDs. The initial 176 pages received a source-level review and local DOM smoke check; redirects were inspected separately.
- Local DOM/JavaScript checks reported no uncaught errors. Canvas exports used a real raster renderer: all six PNG files were produced, with sheet add/clear, print callback, missing-label error, card-library download, note output/copy, and editable visit-plan checks.
- Existing calendar filter and expanded-map suites passed.
- Browser execution was blocked by the environment. Local DOM/canvas tests are not a complete desktop/mobile visual or browser-compatibility audit. Printer dialogs, speech voices and third-party maps were not exercised in a real browser.
- The editorial rights checker passed its stated scope: HTML media references, retired logos and affiliate patterns; it is not complete legal review.
