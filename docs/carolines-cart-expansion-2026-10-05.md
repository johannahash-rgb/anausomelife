# Caroline’s Cart directory expansion — October 5, 2026

Added 29 listings, taking the directory from 41 to 70. Nineteen additions are supported by Walmart’s current nationwide policy; ten Target additions are explicitly unconfirmed chain-report leads. This is not 29 newly observed carts. No store was contacted, and no current cart count, storage position, condition or availability was inferred. Existing row-level review dates remain unchanged.

## Evidence

Walmart policy rechecked: https://corporate.walmart.com/purpose/making-shopping-more-accessible-for-everyone and https://corporate.walmart.com/content/corporate/en_us/purpose/belonging.html state all U.S. Walmart stores provide Caroline’s Carts. Branch addresses and main telephone numbers came from each official store page, linked below. This supports a policy-based listing, not a live branch inventory.

Target: https://idrpp.usu.edu/uatp/blog/2025/carolines-cart (April 14, 2025) identifies the retailer but no branches. https://corporate.target.com/news-features/article/2016/02/carolines-cart documents the historical rollout and its small-store exception. The ten new Target branches are places to ask, not verified cart locations. The two existing Target historical-report records retain their older local evidence. South Burlington is not represented as part of the 2016 rollout. Manchester’s official store name is South Windsor, but its street address is in Manchester; the town field follows the address. Nashua’s listing is the Amherst Street/Nashua NW branch. Warwick’s is Route 2, not Warwick North.
