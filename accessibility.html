Access

Accessibility.

Accessibility is part of the subject of this site, so it should also be part of how the site works.

Our approach

We aim for readable type, strong contrast, keyboard-accessible navigation, descriptive headings, meaningful link text and layouts that work on smaller screens. We avoid using color alone to communicate meaning.

If something is difficult to access, email @anausomelife and tell us what page you were using and what would make it work better.
